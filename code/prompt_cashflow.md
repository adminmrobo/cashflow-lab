# 현금흐름표 작성 프롬프트 (생성AI용)

아래 블록을 생성AI(ChatGPT, Claude, Gemini 등)에 그대로 붙여 넣고, 마지막의 [자료] 자리에 재무상태표·손익계산서·주석을 넣는다.

```text
너는 회계 담당자이자 파이썬(pandas) 개발자다.
아래 [자료]로 현금흐름표의 영업활동 현금흐름을 간접법과 직접법 두 가지로 계산하는 파이썬 코드를 써라.

[지킬 원칙]
1. 현금의 범위: 현금및현금성자산(취득 당시 만기 3개월 이내)만 현금으로 본다. 단기금융자산은 현금이 아니라 투자활동 항목이다.
2. 세 활동 구분: 영업(매출·매입·급여 등 주된 활동), 투자(금융자산·유형자산·무형자산·대여금·보증금의 취득과 처분),
   재무(차입·상환·유상증자·배당). 외부 투자 '유치'(유상증자)는 투자활동이 아니라 재무활동이다.
3. 간접법 다섯 계단: ① 당기순이익(손실) → ② 현금 유출이 없는 비용 가산 → ③ 현금 유입이 없는 수익 차감
   → ④ 영업 관련 자산·부채 변동(자산 증가 −, 감소 + / 부채 증가 +, 감소 −) → ⑤ 영업활동 현금흐름.
4. 투자·재무활동 손익(처분이익·처분손실)은 영업활동에서 되돌린다.
5. 직접법: 고객으로부터 받은 현금, 비용으로 지급한 현금, 이자·법인세를 항목별로 구한다.
6. 현금이 오가지 않은 거래(예: 장기대여금의 유동성 대체)는 현금흐름표 본문에 넣지 않는다.
7. 모든 금액은 원 단위 정수로 다루고, 유출은 음수로 적는다. 계정과목 이름은 한글 그대로 쓴다.

[검산 — 코드에 assert로 넣어라]
A. 간접법 합계 = 공시된 영업활동 현금흐름
B. 직접법 합계 = 간접법 합계
C. 영업 + 투자 + 재무 = 재무상태표 현금및현금성자산의 기말 − 기초
D. 재무상태표 기말 − 기초 증감과 간접법 조정액을 계정별로 대조하고, 차이가 나는 계정은 따로 표로 보여 줘라
   (차이는 오류가 아닐 수 있다. 주석에서 원인을 찾을 항목 목록으로 낸다).
E. 투자활동·재무활동 소계 = 공시된 소계 (활동 분류가 맞는지)

[출력]
- 간접법 표(계단, 계정과목, 금액), 직접법 표, 세 활동 요약, 검산 결과 표를 print 한다.
- 금액 표시는 억원(소수 첫째 자리)으로, 계산은 원 단위로 한다.
- 코드 맨 위에 자료를 사전(dict)으로 넣어 파일 없이 Colab에서 바로 실행되게 한다.

[자료]
{재무상태표·손익계산서·현금흐름표·주석을 붙여 넣는다}
```

## 왜 이렇게 쓰나

| 프롬프트 부분 | 막으려는 실수 |
|---|---|
| 1 현금의 범위 | 단기금융자산(중금채 등)을 현금에 섞어 기말 현금이 공시와 달라짐 |
| 2 세 활동 구분 | '투자 유치'를 투자활동에 넣음 (검산 E가 잡음) |
| 3 다섯 계단과 부호 | 자산 증가에 + 를 붙임 |
| 4 처분손익 | 처분이익을 영업현금에 남겨 두 번 셈 |
| 6 비현금거래 | 대여금 유동성 대체를 현금 유출로 넣음 |
| 검산 A~E | 위 실수를 코드가 스스로 잡게 함 |
